# Simulateur-de-CTA

Application Python de simulation d'une centrale de traitement d'air (CTA).

## Objectif

Ce projet vise à configurer et simuler les principaux modules d'une CTA, puis à effectuer les calculs liés au traitement de l'air.

## Modules étudiés

- Filtration
- Batterie chaude
- Batterie froide
- Ventilateur
- Humidificateur
- Récupérateur de chaleur

## Technologies

- Python

## Lancement

Le programme principal sera lancé avec :

```bash
python main.py
```
